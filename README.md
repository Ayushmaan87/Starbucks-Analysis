Starbucks Beverage Analysis Dashboard
Project Overview

An interactive Power BI dashboard designed to analyze Starbucks beverage data, nutritional values, caffeine content, and product categories. The dashboard transforms raw beverage information into meaningful business insights through dynamic visualizations and KPI tracking.

Purpose

The goal of this project is to explore Starbucks beverage offerings and understand nutritional patterns, caffeine distribution, calorie content, and beverage category performance to support data-driven decision-making.

Data Source

1. Starbucks Beverage Nutrition Dataset
2. Contains beverage details such as:
  a. Beverage Name
  b. Beverage Category
  c. Beverage Preparation Type
  d. Calories
  e. Sugar Content
  f. Caffeine Content
  g. Protein Content
  h. Geographic Location Data (Latitude & Longitude)

Tools & Technologies Used

1. Power BI
2. Power Query
3. DAX (Data Analysis Expressions)
4. Data Modeling
5. Interactive Visualizations
6. KPI Reporting
   
Dashboard Features

1. KPI Cards displaying:
  a. Total Beverages
  b. Average Sugar
  c. Average Calories
  d. Average Caffeine
2. Line Chart for calorie analysis across beverage categories
3. Donut Chart showing beverage category distribution
4. Column Chart comparing average caffeine levels
5. Bar Chart analyzing caffeine content by beverage
6. Geographic Map visualization using latitude and longitude data
7. Interactive slicers for:
   a. Beverage Preparation Type
   b. Protein Content

Key Highlights

1. Tracks nutritional characteristics of Starbucks beverages
2. Identifies high-caffeine and high-calorie drinks
3. Compares beverage categories using interactive visuals
4. Provides geographical visualization of Starbucks-related location data
5. Enables dynamic filtering for deeper analysis

Insights Generated

1. Beverage categories contribute differently to calorie intake
2. Certain beverages contain significantly higher caffeine levels
3. Sugar and calorie trends vary across product categories
4. Interactive filtering helps uncover nutritional patterns

Advantages

1. Easy-to-understand visual analytics
2. Interactive exploration of beverage nutrition data
3. Supports health-conscious product analysis
4. Helps identify beverage trends and category performance
5. Provides quick access to key nutritional metrics
